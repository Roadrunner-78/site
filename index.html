First, what is a repository?

An operating notebook for you and your AI.

This workspace is a repository: an operating notebook with what your AI assistant needs to know, how you want work done, and what is happening in your day-to-day operations. A guide points the assistant to the right information for each job.

You and your AI assistant keep its files up to date together. As you work, the assistant can help record new information, correct instructions and refine the repository to match your vision. What you improve together gives the assistant a better starting point for the next job.

The method

Build it together. Learn to run it yourself.

Your coach helps you design the repository, set up the tools and use them on real work. You learn why each part is there and how to keep it useful.

01

Design your repository.

Start with one job you want help with. Together, choose the information it needs, the steps to follow and how you will check the result. If you already use AI, we can review useful context from those conversations and confirm it against your current sources.

Your coach uses an AI repository advisor to review the plan with you. We agree the first design before installing the tools, then improve it as you use it.

02

Set it up. Learn the routine.

Set up VS Code, the app where you work with your files, and connect the AI tool we agree on. Set up GitHub in your own account: it holds an online copy of your repository and its saved history.

  • Ask for work, review the edits and save a checkpoint.
  • Send and receive changes between your computer and GitHub, and learn to recover a mistake.
  • Where your tools support it, practice continuing from your phone. We test that connection together.
The technical words, explained as we use them
Git and commits
Git records the changes you choose to keep. A commit is a named checkpoint; saving a file or sending it to GitHub is a separate step.
Local and online copies
Local means on your computer. GitHub holds an online copy. You learn to send and receive changes so you are working from the right version.
The AI's working space
A sandbox limits what an assistant can access or change. It may run on your computer or elsewhere. We check which files it can see and how its edits reach your repository.
APIs and Playwright, when needed
An API lets programs exchange requests and information. Playwright lets a program operate a browser. We introduce these when your work calls for them, with their access and costs agreed first.

03

Use it. Improve it. Run it yourself.

Do real work with the repository. Check drafts against your sources, save and test better instructions, and leave the next action ready for a new session. Learn to spot outdated information, fix broken references and resolve conflicting instructions.

  • Complete a real job without your coach checking it first, then a different kind of job. Each must be usable by its recipient.
  • Keep your workspace and an operating guide you can use yourself.

The goal: your own AI advisor.

As your understanding grows, we help you build your own AI advisor using the same repository method. You learn to check its advice and maintain the guidance it uses, so you can run and improve your workspace without our ongoing coaching.

What you become able to do

Build the ability to carry on.

Five practical abilities guide the work. We check them on your tasks.

  1. 01

    Use your sources. Recover a change.

    Complete a task only your own files could support. In a practice copy, deliberately break a file and restore it.

  2. 02

    Save and test a correction.

    Save a correction in your own words, check it on representative examples, and choose one task to keep outside the system.

  3. 03

    Complete different work independently.

    Finish a real job without your coach's check; its recipient uses it. Then complete a different kind of job under the same conditions.

  4. 04

    Keep the repository current.

    Find and repair stale material, a broken reference or conflicting instructions. If none arises, run the maintenance check in a session.

  5. 05

    Carry on independently.

    Run the next job and maintain the repository without your coach's approval.
